      LECTURE STUDIO

      Import. Compare. Assemble.

      Start with the complete lecture files.

      Import both HTML versions. The first creates a working copy automatically. The second becomes your reference. Use the project menus to switch versions or working decks.

      Copy the slides you need.

      Select one or more reference cards, then use Copy →. Linked interactions can travel with their slides. Drag cards in the working deck to reorder them. Move → moves between editable working projects; imported originals cannot be changed.

      Edit what students see.

      Choose a working slide, open Text, then click a line in the preview or select it from the text list. Vector-outline letters become editable SVG text; the surrounding artwork remains vector. The replacement uses a system font, so its appearance may differ slightly. Index titles and descriptions are edited separately in Slide.

      For interactive screens, edit the title, subtitle, question, answers, and teaching notes. Model diagrams and their code come from the selected export runtime.

      Keep an editable master.

      Save workspace stores every imported version and working deck in one JSON file. Save it to iCloud Drive to move between devices. Automatic saves are local to this browser, not cloud synchronization.

      Publish only after testing.

      Export lecture preserves the native lecture shell, figures, motion events, and supported models. Exported IDs are made unique. The new Versión editada route follows your order. Shared media and model implementations come from the selected runtime. Test full-screen navigation, links, motion, video, and every interaction before replacing a published lecture.

      Only native Aula interactiva HTML with a viva-data scene block is supported. This is not a PDF or PowerPoint editor. Import the lecture file, not the course app’s index.html. The editor does not upload your files or execute lecture scripts in editing previews. Only test and open lecture files you trust.
